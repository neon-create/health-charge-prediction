# Health Insurance Charge Prediction

## Project Overview

This project was completed as a team capstone during my data science training at TechCrush. The goal was to build a Linear Regression model that predicts health insurance charges based on patient attributes.

Using the Medical Cost Personal Dataset, we explored how factors such as age, BMI, smoking status, sex, number of children, and region relate to insurance costs.

## Problem Statement

The project addressed the challenge of estimating insurance charges using general assumptions rather than data-driven insights. Our goal was to build a predictive model that could help an insurance analytics company better understand insurance costs and support more informed business decisions.

## Model Evaluation

The Linear Regression model was evaluated using the following metrics:

| Metric | Result |
|---|---:|
| R² | 0.81 |
| Mean Absolute Error (MAE) | $4,177 |
| Root Mean Squared Error (RMSE) | $5,956 |

### What the Results Mean

- **R² (0.81):** The model explains approximately 81% of the variation in insurance charges in the evaluated dataset.
- **MAE ($4,177):** The average absolute difference between the actual and predicted charges was approximately $4,177.
- **RMSE ($5,956):** The model's prediction errors, with larger errors penalized more heavily, resulted in an RMSE of approximately $5,956.

These metrics help assess how well the model predicts insurance charges. They do not, by themselves, establish that the model is suitable for real-world insurance pricing.
